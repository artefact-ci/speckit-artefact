# @artefact-ci/sdd

L'installeur : `npx @artefact-ci/sdd init` installe l'extension git, l'extension et le preset, copie les agents, réapplique les hooks git et génère `stack.yml` et la constitution. Arrive en phase 4.

Squelette du paquet : l'exécuteur de `specify` (Spec Kit épinglé à la version 1.3.2, lancé via `uvx`).
