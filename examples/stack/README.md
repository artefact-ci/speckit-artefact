# examples/stack/

Exemples de `.specify/stack.yml`, le fichier qui décrit la stack d'un projet aux commandes (schéma : [`docs/stack.md`](../../docs/stack.md)).

- `nx.yml` : nx-react-nestjs, relevé sur le boilerplate.
- `bun-hono.yml` : API Bun + Hono sans front, d'après l'exemple du plan pour avia-agent ; à valider sur le projet en phase 6b.
- `nextjs.yml` : application Next.js ; valeurs indicatives, à valider sur avia-client en phase 6b.
